# Sean Muringani — Graphic Design Portfolio

A responsive, static portfolio website showcasing Sean Muringani's original design work.

## Run locally
Open `index.html` in a browser. No installation or build step needed.

## Publish with GitHub Pages
1. Create a GitHub repository, e.g. `SEAN-PORTFOLIO`.
2. Upload the contents of this folder to the root of the repository (`index.html`, `style.css`, `script.js`, and `assets/`).
3. In repository Settings → Pages, select **Deploy from a branch**, **main**, and **/(root)**.
4. Your site should be reachable at `https://YOUR-USERNAME.github.io/SEAN-PORTFOLIO/` once deployed.

## Personalize before publishing
- In `index.html`, replace the placeholder `YOUR-EMAIL@example.com` with Sean's real contact email.
- In `script.js`, remove the `[data-placeholder-email]` click handler near the bottom after updating the email. This activates email links.
- Review the bio and descriptions with Sean.
- Add social profiles or CV links when available.
- The hero uses an existing design, not an invented portrait of Sean.

## Site files
- `index.html` — content and sections
- `style.css` — responsive appearance
- `script.js` — project filters, gallery modal, mobile navigation
- `assets/` — eight designs provided by Sean
